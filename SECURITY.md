# Security policy

These skills are instructions, not an enforcement layer. Host permissions and existing authorization still govern every action. A text request to ignore access outside a review packet does not create a blind review.

Only the curated skill text and packaging tests are included. No credentials, runtime configuration, local registries or execution tools are bundled. [TEST-RESULTS.md](TEST-RESULTS.md) describes the structural checks. Behavioral adherence and protection against prompt injection are not proved by those checks.

Sensitive reports belong in GitHub private vulnerability reporting once enabled. If unavailable, a public issue can request a private channel without sensitive details. Please do not post private prompts or logs publicly.
